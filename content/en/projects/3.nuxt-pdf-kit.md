## Project Overview

**Nuxt PDF Kit** is an independent open-source module for Nuxt 3 & Nuxt 4 providing a full-featured, turnkey PDF viewer with seamless theme customization.

### Key Features

- **Full-featured Toolbar**: Complete support for page navigation, zoom, document rotation, printing, and file downloads.
- **Interactive Text Search**: In-document keyword search with visual text highlighting.
- **Nuxt UI Integration**: Powered by Nuxt UI and Tailwind CSS v4 for native dark mode and theme consistency.
