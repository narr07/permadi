## Finding the Main Idea Is a Skill, Not a Fact to Memorise

Plenty of primary school students read fluently yet struggle with one simple question: what is this paragraph actually about? Spotting the main idea takes repeated practice, and textbook exercises rarely make that practice engaging.

**MIPO** (*Media Mencari Ide Pokok*) is a learning tool for Indonesian-language lessons built around that gap. It started as a research and development project and has kept evolving until anyone can use it straight from a browser.

## Four Ways to Learn in One App

- **Lessons**: learning goals, what a main idea is, topic and supporting sentences, paragraph types, step-by-step strategies, and worked examples.
- **Levelled practice**: 32 questions across 4 levels (Beginner, Basic, Intermediate, Advanced). Each level unlocks only after the previous one, and awards 1 to 3 stars.
- **Main Idea Chase game**: 12 rounds and 3 lives. Students find the topic sentence, pick the "umbrella" sentence for a set of details, or catch the sentence that doesn't belong.
- **Stories**: 12 short reading passages. Six include an answer key for each paragraph's main idea, revealed after reading.

## Technology

MIPO is built with **Flutter**, so one codebase runs on Android, iOS, and the web. GitHub Actions rebuilds the web version on every change, once `flutter analyze` and `flutter test` pass. Progress stays on the student's device and can be cleared at any time from the About page.

::tip
Because progress lives on the device, teachers can use MIPO in class without creating student accounts.
::
