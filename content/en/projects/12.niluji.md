## Digital Exams That Don't Wait for a Signal

Many primary schools want to move to computer-based tests, but their internet connection can't be trusted. One network drop in the middle of an exam means dozens of students starting over.

**[Niluji](https://narr07.github.io/niluji/)** removes that dependency. The teacher runs a single desktop app, and students open the exam page on their own phones or laptops over the same WiFi or hotspot. No internet, and nothing for students to install.

## How It Works

The **Tauri 2** app on the teacher's computer runs an embedded HTTP server (**axum**). That server serves both the admin dashboard and the student exam page over a local IP address. Questions, student records, and results live in a local **SQLite** database (WAL mode with 14-day automatic backups), so exams run reliably with no cloud service at all.

## Key Features

- **Multi-format question bank**: organise questions by grade, subject, and paper type (midterm, final, practice) for both multiple choice and essays, complete with live preview.
- **Word (.docx), Excel (.xlsx), CSV, & Markdown Bundle (.zip) import**: import exam papers complete with inline question images and option images (A–E), or pull question packages from a public GitHub repository.
- **Layered exam security**: each student receives a 6-digit PIN on a printable QR Exam Card, exam token verification, **Single-Device Lock**, and server-authoritative countdown timers.
- **Real-time proctor controls**: monitor live student progress, unlock a student's session if their phone battery dies, grant extra time (`+10 minutes`), or force-submit sessions directly from the proctor dashboard.
- **Mobile & laptop friendly CBT portal**: includes question bookmarking (*Ragu-ragu*), font size controls (`A-` / `A` / `A+`), resilient auto-save with offline retry queue, and `A–D` keyboard shortcuts.
- **Weighted grading & item analysis**: combine multiple-choice and essay scores with custom percentage weights, alongside item difficulty charts and **distractor analysis** (A/B/C/D/blank distribution).

## Technology

The interface is built with **Nuxt 4**, **Nuxt UI 4**, and Tailwind CSS 4. The backend runs on **Tauri 2** with Rust, `rusqlite`, and `axum`.
