## Digital Exams That Don't Wait for a Signal

Many primary schools want to move to computer-based tests, but their internet connection can't be trusted. One network drop in the middle of an exam means dozens of students starting over.

**Niluji** removes that dependency. The teacher runs a single desktop app, and students open the exam page on their own phones or laptops over the same WiFi or hotspot. No internet, and nothing for students to install.

## How It Works

The **Tauri** app on the teacher's computer runs an embedded HTTP server (axum). That server serves both the admin dashboard and the student exam page over a local IP address. Questions, student records, and results live in a local **SQLite** database, so exams run with no cloud service at all.

## Key Features

- **Question bank**: organise questions by grade, subject, and paper type (midterm, final, practice), for both multiple choice and essays.
- **Optional online import**: pull `.xlsx` question templates from a public GitHub repository, review them, and import them into the local bank. Once imported, everything runs offline.
- **Exam scheduling**: set exams per class and subject, with an access window and a per-student time limit.
- **Separate multiple-choice and essay sessions**: students finish the multiple-choice part first, then the essays, which the teacher grades by hand.
- **Results and analytics**: live progress for each student, inline essay grading, and charts for question difficulty and student ranking.
- **QR code sign-in** for students, handy when every device is different.

## Technology

The interface is built with **Nuxt 4**, **Nuxt UI 4**, and Tailwind CSS 4. The backend runs on **Tauri 2** with Rust, `rusqlite`, and axum.
