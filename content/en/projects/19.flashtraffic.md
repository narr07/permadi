## Authentic Desktop Traffic Simulation & Multi-Channel Attribution

Testing website infrastructure resiliency and verifying Google Analytics 4 (GA4) attribution models requires realistic traffic patterns that mimic real human visitors. Cloud-based bot services are often heavily flagged by anti-bot systems or require costly recurring subscriptions.

**[FlashTraffic](https://narr07.github.io/flashtraffic/)** is a desktop application designed for Windows that bridges visual ease-of-use with raw native Rust performance.

## Dual-Engine Architecture

1. **System Browser Borrowing**: Leverages the user's existing desktop browsers (Microsoft Edge, Google Chrome, Brave, Firefox, or custom paths) without forcing large Playwright runtime downloads. Supports interactive **Visual Window Mode** and silent **Headless Mode**.
2. **Native Rust Asynchronous HTTP Engine**: An ultra-low footprint engine built on Tokio and Reqwest, requiring less than 30 MB of RAM for high-throughput concurrency testing.

## Key Capabilities

- **Multi-Channel Simulation**: Direct navigation, Organic Search with search engine query injection, and social/referral traffic simulation.
- **UTM Campaign Studio**: Interactive generator and validator for GA4 marketing tags.
- **Humanized Simulation Physics**: Smooth Bézier mouse paths, variable scrolling pauses, and multi-page domain exploration.
- **Smart Sitemap & URL Discovery**: Automatic XML sitemap deduplication and filter-aware URL routing.
- **Proxy Context Isolation**: Full support for HTTP, HTTPS, SOCKS4, and SOCKS5 proxy rotation.
