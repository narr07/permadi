## Karya Lokal Butuh Panggung Lokal

Developer dan desainer di Majalengka terus berkarya, tetapi hasilnya tersebar di GitHub, Behance, dan media sosial masing-masing. Sesama kreator di kota yang sama sering tidak tahu siapa sedang membangun apa.

**Majalengka Tech** mengumpulkan karya-karya itu dalam satu etalase. Setiap kreator punya profil sendiri, setiap proyek punya halamannya, dan pengunjung bisa memberi apresiasi serta komentar.

## Yang Bisa Dilakukan di Situs Ini

- **Showcase proyek**: semua proyek yang sudah terbit bisa disaring per kategori, diurutkan dari yang terbaru atau terpopuler, dan dicari berdasarkan judul, teknologi, atau nama kreator.
- **Halaman proyek**: galeri hingga 8 gambar, cerita di balik proyek, peran kreator, teknologi yang dipakai, serta tautan ke demo, desain, dan kode sumber.
- **Profil kreator** di `majalengka.tech/username`, lengkap dengan kartu kreator yang bisa diunduh dan dipakai sebagai pratinjau link.
- **Dashboard kreator**: unggah proyek baru, simpan sebagai draf, edit profil, dan cek kelengkapan profil.
- **Halaman pengelola**: kelola pengguna dan proyek, termasuk memilih proyek untuk Pilihan Kurator.
- **Konten untuk alat AI** di `/llms.txt` dan `/llms-full.txt`.

## Teknologi

| Bagian | Teknologi |
|---|---|
| Framework | Nuxt 4 |
| Komponen UI | Nuxt UI 4 dan Tailwind CSS 4 |
| Panduan dan changelog | Nuxt Content 3 |
| Database dan file | NuxtHub dengan Cloudflare D1 dan R2, lewat Drizzle ORM |
| Login | Better Auth (email, GitHub, Google) |
| Hosting | Cloudflare Workers |

Proyek ini terbuka untuk kontribusi. Laporan bug, usulan, dan pull request diterima lewat repositorinya.
