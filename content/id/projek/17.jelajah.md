## Satu Jendela untuk Pekerjaan Tiga Aplikasi

Pengguna Windows yang serius soal file biasanya memasang beberapa alat tambahan: Everything untuk mencari, PowerToys untuk mengganti nama massal atau melihat isi file, dan TreeSize untuk mencari tahu ke mana ruang disk habis. Akibatnya, pekerjaan sehari-hari berpindah-pindah antara empat jendela.

**Jelajah** (artinya *explore*) menyatukan semuanya. Tampilan dan perilakunya mengikuti `explorer.exe`, jadi tidak perlu belajar dari awal, tetapi alat-alat tadi sudah tersedia di dalamnya.

## Fitur Utama

**Terasa seperti Explorer bawaan**
- Tab, dua panel (F6), panel navigasi, serta panel detail dan pratinjau.
- Hapus masuk ke Recycle Bin, sedangkan salin dan pindah memakai shell Windows lengkap dengan dialog progres dan konflik bawaannya.
- Ikon file asli Windows, dialog Properties yang asli, menu konteks Explorer lengkap, serta shortcut yang sudah familiar seperti F2, F5, dan Ctrl+T.

**Pencarian instan**
- Indeks nama file untuk semua drive. Di README, pencarian atas 2,7 juta nama tercatat selesai dalam sekitar 0,2 sampai 10 milidetik, dan indeks diperbarui otomatis saat file berubah.
- Mode **Fast Index** opsional membaca NTFS MFT seperti Everything, lewat helper terpisah, sehingga aplikasi utama tidak pernah berjalan sebagai admin.
- Pencarian isi file memakai tgrep berbasis indeks trigram.

**Alat file PowerToys**
- Peek (Space) untuk melihat kode, gambar, Markdown, PDF, video, dan audio.
- PowerRename, Image Resizer, File Locksmith, template New+, Text Extractor (OCR Windows), Command Palette, dan Paste as File.

**Analisis disk ala TreeSize**
- Pemindaian paralel sampai ke folder terdalam, ukuran per jenis file, dan daftar file terbesar. Hasilnya disimpan di memori sehingga subfolder mana pun bisa dibuka seketika.

## Teknologi

Seluruh pekerjaan file dikerjakan **Rust** lewat **Tauri 2**. **Nuxt 4** dan **Nuxt UI** hanya bertugas menggambar antarmuka.
