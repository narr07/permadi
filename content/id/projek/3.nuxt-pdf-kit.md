## Gambaran Projek

**Nuxt PDF Kit** adalah modul open-source independen untuk ekosistem Nuxt 3 & Nuxt 4 yang menyediakan antarmuka viewer PDF kaya fitur dan siap pakai dengan kustomisasi tema penuh.

### Fitur Utama

- **Full-featured Toolbar**: Dukungan navigasi halaman, zoom, rotasi dokumen, cetak (*print*), dan unduh file.
- **Pencarian Teks Interaktif**: Pencarian kata kunci dalam dokumen PDF dengan penanda sorot (*highlighting*).
- **Integrasi Nuxt UI**: Menggunakan Nuxt UI dan Tailwind CSS v4 untuk konsistensi visual dan dark mode otomatis.
