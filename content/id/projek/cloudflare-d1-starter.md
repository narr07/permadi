# Nuxt + Cloudflare D1 Fullstack Starter

Boilerplate siap produksi untuk membangun aplikasi web cepat di jaringan edge global menggunakan Nuxt dan Cloudflare D1.

## Arsitektur

- **Edge Deployment**: Kompatibel dengan Cloudflare Pages Functions.
- **Type-safe ORM**: Drizzle ORM terintegrasi dengan migrasi otomatis.
- **Local Dev Simulation**: Simulasi database SQLite lokal menggunakan Miniflare / Nitro D1 adapter.
