## Simulasi Trafik & Uji Beban Website Nyata dari Desktop

Memastikan keandalan infrastruktur web dan keakuratan atribusi analitik pemasaran digital membutuhkan pengujian trafik yang merefleksikan perilaku manusia sebenarnya. Alat simulasi berbasis server sering kali mudah terdeteksi sebagai bot atau memerlukan konfigurasi infrastruktur cloud yang rumit dan mahal.

**[FlashTraffic](https://narr07.github.io/flashtraffic/)** dirancang untuk Windows sebagai platform desktop modern yang menggabungkan kemudahan antarmuka grafis dengan mesin eksekusi ganda berkecepatan tinggi.

## Arsitektur Dual Engine

FlashTraffic menghadirkan dua pilihan mesin simulasi sesuai skenario pengujian:

1. **System Browser Borrowing**: Memanfaatkan peramban desktop asli pengguna (Microsoft Edge, Google Chrome, Brave, atau custom path) tanpa perlu mengunduh bundel Playwright/Chromium ratusan megabyte. Dilengkapi mode jendela visual (*Visual Window Mode*) dan mode senyap (*Headless*).
2. **Native Rust Asynchronous HTTP Engine**: Mesin HTTP asinkron berbasis Tokio dan Reqwest yang tertanam langsung di dalam binary aplikasi. Membutuhkan memori ultra-rendah (< 30 MB RAM) untuk pengujian beban berkecepatan tinggi.

## Fitur Unggulan

- **Simulasi Multi-Saluran**: Pengujian saluran Direct, Organic Search (Google, Bing, Yahoo, DuckDuckGo) dengan injeksi kata kunci, dan Referral dari media sosial.
- **UTM Campaign Studio**: Pembuat dan penguji parameter atribusi Google Analytics 4 (GA4) secara presisi.
- **Fisika Perilaku Manusia (Humanized Physics)**: Pergerakan kursor acak kurva kurva Bézier, micro-jitter, scrolling bertahap, dan penelusuran halaman internal domain untuk menekan *bounce rate*.
- **Smart Sitemap & URL Crawler**: Parser sitemap XML otomatis dengan seleksi URL dinamis.
- **Proxy & Geolocation**: Dukungan proxy HTTP, HTTPS, SOCKS4, dan SOCKS5 dengan isolasi konteks peramban.
