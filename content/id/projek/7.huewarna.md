## Tantangan Memilih Palet Warna dalam Desain Antarmuka

Banyak desainer grafis dan developer frontend kesulitan saat memindahkan palet warna dari generator warna biasa ke komponen aplikasi nyata. Palet yang tampak serasi di atas kanvas abstrak kerap bermasalah saat diterapkan pada tombol, kartu informasi, lencana status, maupun tema gelap (*dark mode*).

Tantangan terbesarnya ada pada keterbacaan teks dan rasio kontras aksesibilitas. Kombinasi warna yang tidak memenuhi standar WCAG (*Web Content Accessibility Guidelines*) membuat antarmuka sulit dibaca, terutama bagi pengguna dengan keterbatasan penglihatan.

Proyek **HueWarna** hadir untuk menjawab persoalan tersebut: menyediakan kurasi palet warna yang langsung diuji pada komponen antarmuka nyata secara dinamis.

## Arsitektur & Keunggulan Teknis

Aplikasi dibangun menggunakan **Nuxt 4**, **Nuxt UI v4**, dan **Tailwind CSS v4** dengan fokus pada responsivitas dan ketepatan kalkulasi warna:

- **Simulasi UI Real-Time**: Setiap perubahan palet warna otomatis diterapkan secara instan ke berbagai komponen UI (seperti tombol aksi, kartu produk, formulir input, dan lencana status).
- **Inspeksi Rasio Kontras WCAG**: Perhitungan matematis otomatis untuk memastikan kombinasi warna latar belakang dan teks memenuhi standar kepatuhan AA dan AAA.
- **Dukungan Dual Mode Adaptif**: Pengujian palet warna langsung pada mode terang (*light mode*) dan mode gelap (*dark mode*) untuk memastikan konsistensi visual di segala kondisi pencahayaan.
- **Ekspor Variabel CSS & Tailwind**: Pengguna dapat menyalin nilai palet dalam format HEX, RGB, OKLCH, atau konfigurasi tema siap pakai untuk Tailwind CSS dan Nuxt UI.

::tip
HueWarna menerapkan manipulasi variabel CSS dinamis pada elemen root dokumen, sehingga pergantian tema palet warna berlangsung mulus tanpa merender ulang komponen DOM secara berlebihan.
::

## Fitur Utama

- **Katalog Palet Terkurasi**: Koleksi kombinasi warna harmonis yang teruji untuk berbagai kebutuhan industri digital (SaaS, e-commerce, portofolio, dan media).
- **Simulator Komponen Interaktif**: Tinjau kecocokan warna langsung pada prototipe antarmuka yang dapat diklik dan diuji interaksinya.
- **Kalkulator Harmoni Warna**: Panduan pembuatan skema warna komplementer, analog, triadik, dan monokromatik berbasis teori warna modern.
- **Ekspor Kode Instan**: Salin variabel warna ke clipboard dalam hitungan detik untuk mempercepat alur kerja pengkodean antarmuka Anda.
