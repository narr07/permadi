# Redesign Sistem Bento Portfolio Pribadi

Studi kasus mendalam mengenai transformasi portofolio personal dari struktur layout tradisional menjadi arsitektur modular **Bento Grid** 12-kolom yang dinamis dan berkarakter.

## Latar Belakang & Masalah

Layout portofolio linear konvensional seringkali terasa monoton dan kaku. Konten seperti highlight proyek, artikel terbaru, stack teknologi, dan cuplikan visual diperlakukan sama secara hierarki visual.

## Solusi Desain: Bento Grid System

1. **Hierarki Berbobot**: Mengalokasikan proporsi kartu (1×1, 2×1, 1×2, 2×2) berdasarkan prioritas informasi.
2. **Golden Ratio Scale**: Skala tipografi $\phi \approx 1.618$ untuk membedakan kontras judul kartu secara konsisten.
3. **Floating Island Navigation**: Navbar berbasis 3 modul mengambang dengan efek glassmorphism `backdrop-blur`.
4. **Single Spotlight**: Mempertahankan fokus visual dengan membatasi efek spotlight hanya pada kartu utama.

## Hasil & Dampak

- Interaktivitas dan waktu interaksi pengunjung meningkat secara signifikan.
- Struktur konten lebih ringkas dan dapat dinikmati dalam satu pandangan di desktop maupun mobile.
