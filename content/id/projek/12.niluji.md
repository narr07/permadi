## Ujian Digital Tanpa Menunggu Sinyal

Banyak sekolah dasar ingin beralih ke ujian berbasis komputer, tetapi koneksi internetnya tidak bisa diandalkan. Satu gangguan jaringan di tengah ujian berarti puluhan siswa harus mengulang dari awal.

**[Niluji](https://narr07.github.io/niluji/)** menghilangkan ketergantungan itu. Guru cukup menjalankan satu aplikasi desktop, lalu siswa membuka halaman ujian dari HP atau laptop masing-masing lewat WiFi atau hotspot yang sama. Tidak perlu internet, dan siswa tidak perlu memasang apa pun.

## Cara Kerjanya

Aplikasi **Tauri 2** di komputer guru menjalankan server HTTP (**axum**) di dalamnya. Server itu melayani dashboard admin sekaligus halaman ujian siswa melalui alamat IP lokal. Soal, data siswa, dan hasil ujian tersimpan di **SQLite** lokal (mode WAL + cadangan otomatis 14 hari), sehingga ujian tetap berjalan stabil tanpa layanan cloud.

## Fitur Utama

- **Bank soal multi-format**: kelola soal per kelas, mata pelajaran, dan jenis paket (UTS, UAS, latihan) untuk Pilihan Ganda maupun Esai, lengkap dengan pratinjau langsung.
- **Impor Word (.docx), Excel (.xlsx), CSV, & Bundel Markdown (.zip)**: konversi naskah soal beserta gambar di tengah kalimat dan gambar pada opsi jawaban A–E secara instan, atau tarik paket soal dari repositori GitHub publik.
- **Keamanan sesi berlapis**: setiap siswa mendapatkan PIN 6 digit pada Kartu Peserta ber-QR Code, validasi Token Ujian, **Kunci Perangkat (*Single-Device Lock*)**, serta perhitungan waktu dari sisi server.
- **Kontrol pengawas real-time**: pantau progres pengerjaan tiap siswa secara langsung, buka kunci perangkat jika HP siswa mati, berikan tambahan waktu (`+10 menit`), atau paksa kumpul sesi dari komputer proktor.
- **Portal CBT ramah HP & laptop**: dilengkapi penanda soal *Ragu-ragu*, pengatur ukuran teks (`A-` / `A` / `A+`), indikator simpan otomatis tahan putus koneksi, serta pintasan keyboard `A–D`.
- **Bobot nilai & analisis butir soal**: gabungkan nilai Pilihan Ganda dan Esai sesuai bobot persentase otomatis, lengkap dengan grafik tingkat kesulitan dan **analisis pengecoh** (sebaran pemilih opsi A, B, C, D, dan kosong).
