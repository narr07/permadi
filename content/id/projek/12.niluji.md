## Ujian Digital Tanpa Menunggu Sinyal

Banyak sekolah dasar ingin beralih ke ujian berbasis komputer, tetapi koneksi internetnya tidak bisa diandalkan. Satu gangguan jaringan di tengah ujian berarti puluhan siswa harus mengulang dari awal.

**Niluji** menghilangkan ketergantungan itu. Guru cukup menjalankan satu aplikasi desktop, lalu siswa membuka halaman ujian dari HP atau laptop masing-masing lewat WiFi atau hotspot yang sama. Tidak perlu internet, dan siswa tidak perlu memasang apa pun.

## Cara Kerjanya

Aplikasi **Tauri** di komputer guru menjalankan server HTTP (axum) di dalamnya. Server itu melayani dashboard admin sekaligus halaman ujian siswa melalui alamat IP lokal. Soal, data siswa, dan hasil ujian tersimpan di **SQLite** lokal, jadi ujian tetap berjalan tanpa layanan cloud.

## Fitur Utama

- **Bank soal**: kelola soal per kelas, mata pelajaran, dan jenis paket (UTS, UAS, latihan), untuk pilihan ganda maupun esai.
- **Tarik soal online (opsional)**: ambil template soal `.xlsx` dari repositori GitHub publik, periksa, lalu impor ke bank soal lokal. Setelah diimpor, semuanya berjalan offline.
- **Penjadwalan ujian**: atur ujian per kelas dan mata pelajaran, lengkap dengan jendela akses dan durasi pengerjaan per siswa.
- **Sesi PG dan esai terpisah**: siswa menyelesaikan pilihan ganda lebih dulu, lalu esai. Nilai esai dinilai manual oleh guru.
- **Hasil dan analitik**: progres real-time per siswa, penilaian esai langsung di halaman hasil, serta grafik tingkat kesulitan soal dan peringkat siswa.
- **Login siswa lewat QR code**, praktis untuk perangkat siswa yang beragam.

## Teknologi

Antarmuka dibangun dengan **Nuxt 4**, **Nuxt UI 4**, dan Tailwind CSS 4. Sisi backend memakai **Tauri 2** dengan Rust, `rusqlite`, dan axum.
